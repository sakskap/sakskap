## Featured projects

### 🧭 Vision Agent for Android Accessibility
AI agent that helps blind and low-vision users navigate Android apps via an accessibility service + Gemini.  
- Uses: Android AccessibilityService, ADB tooling, Gemini 2.5, multi-step agent loop  
- Focus: Reliability, safe automation, and clear reasoning logs  

### 🧪 Community Notes: Early Consensus Reliability
Research + codebase analysing **174M+ ratings** from X’s Community Notes to predict early “helpfulness” outcomes.  
- Uses: Python, Pandas, scikit-learn / statsmodels, logistic regression, calibration  
- Focus: Early-stop rules, rater reliability, disagreement / entropy metrics  

### 🎙️ UPSC AI Interview Panel
Multi-agent AI interview board that simulates an UPSC-style panel with different personas.  
- Uses: Python, React/Vite frontend, Gemini, streaming APIs  
- Focus: Prompting, evaluation, and multi-role orchestration  

### 📍 Local Culture / Events Mapping (CEEN.live)
Backend + tooling for extracting events from posters and mapping them to real-world locations.  
- Uses: Django, PostgreSQL, React, Google Maps APIs  
- Focus: OCR pipelines, geocoding, and building a local culture graph
